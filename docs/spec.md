# AI 건강 길잡이 사양

## 무엇을 만드는가

70대 어르신이 혼자 쓰는 건강 기록 웹페이지.
불편한 곳을 말하면 (1) 집에서 해볼 것을 보여주고 (2) 날짜별로 저장되고
(3) 병원에서 의사에게 화면째로 보여줄 수 있다.

핵심은 기록이고, 안내는 매일 열게 만드는 유인이다.

## 안내는 두 종류이고 절대 섞이지 않는다

| | 근거 있는 정보 | 전해 내려오는 것 |
|---|---|---|
| 내용 | 생활습관 | 차·민간요법 |
| 출처 | 공공기관 — 화면에 표시 | 없음 |
| 데이터 | lifestyle-data.js | tea-data.js |

화면에서 근거 있는 정보를 위, 차를 아래에 두고 구분선과 소제목을 넣는다.

- 위 묶음 제목: `집에서 해보실 것`
- 아래 묶음 제목: `예로부터 드시던 차`

## 화면 흐름

```
홈 → 말하기 → 결과 → 기록 → 진료용
```

## 1. 홈

- 제목 `건강 길잡이`, 그 아래 `어디가 불편하세요?`
- 8개 버튼 2열 4행

| 버튼 | 코드 | 예시 문구 |
|---|---|---|
| 아프다 | pain | 무릎·허리·어깨·머리 |
| 속이 안 좋다 | stomach | 소화·속쓰림·변 |
| 숨·기침 | breath | 기침·가래·숨참 |
| 잠 | sleep | 못 잔다·새벽에 깬다 |
| 기운·어지럼 | energy | 힘없다·어지럽다·깜빡한다 |
| 눈·귀 | eyeear | 침침하다·잘 안 들린다 |
| 소변 | urine | 자주 마렵다·시원찮다 |
| 기분 | mood | 울적하다·답답하다 |

- 아래 폭 전체 버튼: `잘 모르겠다` (unknown)
- 맨 아래: `내 기록 보기`

## 2. 말하기

- 맨 위에 고른 항목 이름
- 가운데 아주 큰 원형 버튼 `누르고 말씀하세요`
- 그 아래 `글자로 쓰기` (큰 입력창)
- 맨 아래 `뒤로`
- 음성 미지원 브라우저면 말하기 버튼을 숨기고 입력창을 바로 띄운다.
  오류 메시지 대신 그냥 입력창이 나오게 할 것

## 3. 결과

1. **내가 한 말** — 큰 글씨 + `고치기` 버튼 (음성이 자주 틀리므로 필수)
2. `이대로 적어두기` 큰 저장 버튼 → `적어두었습니다`
3. **집에서 해보실 것** — lifestyle-data.js. 카드 아래 작은 글씨 `출처: ○○`
4. 구분선
5. **예로부터 드시던 차** — tea-data.js에서 3개만 무작위.
   아래 `다른 차 더 보기`로 나머지 펼침
   - `TEA_DISCLAIMER` 반드시 표시
   - `TEA_MEDICINE_WARNING` 반드시 표시 (눈에 띄게)
   - 개별 `caution` 값이 있으면 그 카드 안에 표시
   - sleep, urine에서는 `TEA_CAFFEINE_NOTE`도 표시
6. **이럴 땐 병원에 가보세요** — 배경 다르게
7. `처음으로`

**energy·mood·unknown은 3·4·5를 표시하지 않고** 이 문장만:
> 적어두었습니다. 이런 이야기는 나중에 의사 선생님께 보여드리면 도움이 됩니다.

**mood 추가 규칙** — 최근 14일 안에 mood 기록이 3번 이상이면 덧붙인다:
> 요즘 마음이 무거우신 것 같습니다. 가까운 분이나 전문가와 이야기를 나눠보시면 좋겠습니다.
> 정신건강 상담전화 1577-0199

## 4. 기록

- 탭 두 개: `증상별` / `날짜순`
- 증상별: `무릎 — 최근 3개월 7번` 요약 줄, 누르면 펼쳐짐
- 날짜순: 최신이 위. `8월 6일 — 아침에 기침이 심했다`
- 각 기록에 `지우기` (한 번 확인)
- 맨 위에 큰 버튼 `의사에게 보여주기`

## 5. 진료용

- 맨 위: `이 화면을 의사 선생님께 보여드리세요`
- **최근 3개월만**
- 항목별로 묶어 처음 말한 날 / 몇 번 / 어르신이 한 말 그대로
- **요약·해석 문장 절대 금지**
  - O `8월 2일 — 계단 내려올 때 무릎이 시큰했다`
  - X `8월 2일 — 무릎 관절 증상 악화 추정`
- 이 화면에 차·생활습관 정보를 넣지 마라. 기록만
- 맨 아래: `이 화면을 사진으로 찍어 자녀분께 보내셔도 됩니다`
- 인쇄용 스타일 포함

## 데이터

### localStorage

```js
// key: 'healthguide.records.v1'
[
  { id: "1722900000000", group: "breath",
    text: "아침에 기침이 심했다", date: "2026-08-06" }
]
```

### tea-data.js

이미 만들어져 있다. **그대로 사용하고 내용을 수정하거나 추가하지 마라.**

```
TEA_DATA[group] → [{ name, note, caution }]
TEA_DISCLAIMER, TEA_MEDICINE_WARNING, TEA_CAFFEINE_NOTE
```

### lifestyle-data.js

빈 껍데기다. 내용은 사람이 공공기관 자료를 확인해 나중에 채운다.

```js
const LIFESTYLE_DATA = {
  pain: [], stomach: [], breath: [], sleep: [],
  eyeear: [], urine: [], energy: [], mood: [], unknown: []
};
// 항목 예시: { title:"", body:"", source:"", checked:"2026-08" }
```

**이 배열을 임의로 채우지 마라.**
비어 있으면 `집에서 해보실 것` 묶음 자체를 감추고 차만 보여준다.

## 병원 안내 (그대로 넣을 것)

- **아프다** — 넘어지신 뒤에 아플 때 / 다리에 힘이 빠지거나 저릴 때 / 밤에 아파서 잠을 못 주무실 때
- **속이 안 좋다** — 변이 검거나 피가 섞일 때 / 음식을 삼키기 힘들 때 / 이유 없이 살이 빠질 때 / 토가 멈추지 않을 때
- **숨·기침** — 3주가 넘도록 기침이 이어질 때 / 가래에 피가 섞일 때 / 가만히 있어도 숨이 찰 때
- **잠** — 코를 심하게 골면서 자다가 숨이 멎는 것 같다는 말을 들으실 때
- **눈·귀** — 갑자기 한쪽이 안 보일 때 / 갑자기 잘 안 들릴 때 / 눈이 아프고 빨갈 때
- **소변** — 소변에 피가 섞일 때 / 소변이 나오지 않을 때 / 열이 나면서 옆구리가 아플 때
- **기운·어지럼** — 자꾸 어지러워 넘어질 뻔할 때 / 이유 없이 기운이 없는 날이 이어질 때 / 자꾸 깜빡하는 일이 늘 때
- **기분** — 마음이 무거운 날이 2주 넘게 이어질 때

**energy 항목에는 이것을 빨간 칸으로 맨 위에 크게:**
> 갑자기 한쪽 팔다리에 힘이 빠지거나, 말이 어눌해지거나, 입이 돌아가면 **곧바로 119**에 전화하십시오.
